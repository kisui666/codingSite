Web → uni-app x 速查表

写代码时最常卡住的不是"不会写"，而是"Web 里我是那么写的，这里该写什么"。 这一页把结构、样式、逻辑、存储网络、路由、工程配置的对应关系一次列全，并单独标出在 App 端根本不生效的写法。 忘记时回来搜关键词即可，例如搜 localStorage、div、float。

A.1

逐条对照速查

按需查阅
想做的事Web 写法uni-app x 写法关键差异 / 坑
页面文件index.html + .js + .csspages/index/index.uvue（三段式合一）页面必须登记到 pages.json，第一项是启动页
容器<div><view>view 天生是 flex 容器，默认纵向排列
文字<p> <span><text>文字必须放在 text 里；写在 view 里会被自动包一层无样式的 text，样式改不动
图片<img src="assets/a.png"><image src="/static/a.png" mode="aspectFill">图片必须放 static/ 才会被打包；也可以直接用网络地址
可滚动区域overflow: auto + 固定高度<scroll-view direction="vertical">页面本身默认可滚动；scroll-view 需要限定高度（用 flex: 1 或固定高度）
超链接跳转<a href="about.html"><navigator url="/pages/about/about"> 或 @click + uni.navigateTourl 是"页面路径"，不带后缀，且必须是已注册页面
列表ul / li + 拼接 HTML<view v-for="item in list" :key="item.id">用 v-for 渲染，别手动拼字符串；列表项给唯一 :key
全局样式<link rel="stylesheet">写在 App.uvue 的 <style> 里公共 class 放全局是最稳的做法
页面样式页面内的 <style>页面 .uvue 里的 <style>非 Web 平台不支持 scoped；样式隔离由官方策略控制
页面布局方式block 文档流 + floatflex 布局（flex-direction 默认 column）float 完全不支持；横排必须显式写 flex-direction: row
元素间距margin 或 gapmargin（padding 配合）gap / row-gap 不在官方 CSS 属性清单中，别用
尺寸单位px / rem / em / %优先 px（逻辑像素）；rpx 用于按 750px 设计稿等比缩放；支持百分比性能 px > rpx > 百分比；rpx 在平板/折叠屏/横屏会偏大
选择器标签 / 类 / id / 属性 / 伪类只用 class 选择器（单一 class 最稳）标签、#id、属性、通配符 * 在 App 端都不支持
文字样式继承父元素 color 自动传给子元素把样式写在 text（或其 class）上样式不继承，inherit / unset 也不支持
点击态反馈:active 伪类组件的 hover-class 属性view 的 hover-class 默认是 none，要自己指定才会有点击反馈
字体图标::before + content: "\e600"直接把 unicode 字符写在 text 里不支持伪元素，图标字体要用 unicode 直显
层级控制z-index 可任意覆盖z-index 仅在同一层兄弟节点之间生效不能脱离节点树随便"盖住"别人的元素，层级要在结构上设计好
深色模式@media (prefers-color-scheme: dark)主题变更 API + CSS 变量官方提供暗黑模式专题方案，第 3 章会讲
获取元素document.querySelector('.btn')不需要找元素；改响应式变量即可App 端没有 document / window
更新文字el.textContent = name<text>{{ name }}</text>声明式渲染：描述结果，不指挥过程
声明数据let count = 0const count = ref(0) → count.value只有响应式数据变化才会触发界面更新
点击事件el.addEventListener('click', fn)<button @click="fn">写函数名，不加括号；需要传参时用 @click="fn(item)"
显示 / 隐藏el.style.display = 'none'v-if（销毁）或 v-show（隐藏）v-if 不渲染节点，v-show 只切换显示，按开销选择
循环渲染list.forEach(...innerHTML += ...)v-for="(item, i) in list"同时需要 v-if 与 v-for 时，优先用计算属性先过滤
表单双向绑定input.value + oninput<input :value="kw" @input="onInput" />（需要完全受控再加 controlled）官方 input 属性表给的是 value + @input；v-model 属内置指令，未出现在组件属性表中，本课程统一用前者
定时器setInterval / setTimeoutsetInterval / setTimeout（同 JS 内置）页面卸载时记得 clearInterval，否则回调里访问已销毁页面会出问题
弹窗确认alert() / confirm()uni.showModal({ title, content })真机调试时非常好用；showCancel: false 就是 alert 效果
轻提示自己写一个 toast 组件uni.showToast({ title: '已保存' })记得配 icon: 'none' 才是纯文字提示
页面滚到顶部window.scrollTo(0, 0)uni.pageScrollTo({ scrollTop: 0 })跨端 API 统一用 uni. 前缀
本地存储localStorage.setItem(k, v)uni.setStorageSync(k, v) / uni.getStorageSync(k)异步版是 uni.setStorage；同步版写起来更省事，注意别存超大对象
网络请求fetch(url).then(r => r.json())uni.request({ url, method, data, success, fail })返回结构是 res.data；域名要在 manifest.json 里配置合法域名（小程序端必须）
请求封装axios 实例 + 拦截器自己包一层 request() 返回 Promise第 8 章会写一份带统一错误处理的请求封装
图片上传FormData + fetchuni.uploadFile({ url, filePath, name })先 uni.chooseImage 拿到本地路径，再上传
读写剪贴板navigator.clipboarduni.setClipboardData / uni.getClipboardData各端都支持，比浏览器的 clipboard API 更一致
跳转新页面location.href = 'about.html'uni.navigateTo({ url: '/pages/about/about' })路径以 / 开头，不带 .uvue 后缀
替换当前页location.replace(...)uni.redirectTo({ url })登录页跳主页常用 reLaunch（清空页面栈）
切换 tabBar 页—uni.switchTab({ url })tabBar 页面只能用 switchTab 跳转
返回上一页history.back()uni.navigateBack()可以在返回前把参数回传给上一页（第 7 章讲）
页面之间传参URL query / sessionStorageuni.navigateTo({ url: '?id=3' }) + onLoad((options) => {})参数值记得 encodeURIComponent；复杂对象建议用全局状态或存储
页面标题<title>pages.json 里该页面的 style.navigationBarTitleText也可以在运行时用 uni.setNavigationBarTitle 动态改
底部导航栏自己写固定定位的 navpages.json 的 tabBar 配置图标需要普通态与选中态两张图，放 static/
页面生命周期DOMContentLoaded / onloadonLoad / onReady / onPageShow / onUnload组合式 API 中页面的 show/hide 写作 onPageShow / onPageHide
静态资源目录assets/ 或任意路径必须放 static/其他目录里的图片不会被打包；引用路径写 /static/xxx.png
引入第三方库npm install + import插件市场装 uni_modules；蒸汽模式下纯 JS 库也可直接用 npm依赖 window / document 的库不能用于 App 端
应用名 / 图标<meta> + faviconmanifest.json包名、版本号、权限声明都在这里；打包前务必检查
生产构建构建静态文件并部署云打包 / 本地打包生成 APK、IPA、HAPAndroid 可自签安装；iOS 需要证书；鸿蒙需对应工具链
调试方式浏览器 F12HBuilderX 控制台 + 真机基座运行App 端没有 F12；改样式用浏览器预览，验效果必须真机
没有匹配的条目，换个关键词试试（例如 text、请求、图标）。

A.2

危险写法清单：这些在 App 端不生效

写代码前扫一眼

下面这些写法有个共同特点：在浏览器里看起来完全正常，一上真机就悄悄失效（通常不报错，只是没效果）， 所以比语法错误更难查。写完页面请逐条排查。

写法状态为什么正确做法
gap: 12px不支持不在官方 CSS 属性清单内用 margin（配合 padding）制造间距
float: left不支持App 端只支持 flex 与绝对定位改成 flex 布局
display: grid不支持不在官方属性清单内用 flex 换行（flex-wrap: wrap + 百分比宽度）做网格
text { color: red }（标签选择器）不支持App 端只支持 class 选择器给组件加 class，写 .title { color: red }
#app { ... }（id 选择器）不支持同上统一用 class
* { box-sizing: border-box }不支持通配符选择器不支持；而且 ucss 默认就是 border-box什么都不用写
::before / ::after / ::placeholder不支持不支持伪元素多写一个真实 view 节点；占位符样式用 placeholder-class
:active / :hover / :first-child不支持不支持伪类点击态用组件的 hover-class 属性；"首尾项"用数据判断后动态 class
color: inherit / unset不支持样式不继承显式写出具体值
<style scoped>非 Web 不支持App 端没有 scoped 概念，改用官方样式隔离策略直接写 <style>，公共样式放 App.uvue
window / document / localStorage / alert不存在App 端不是浏览器环境（DOM API 仅有极少数可用）用 uni. 系列 API，界面靠改响应式数据
rem / em官方未列出官方长度单位文档只列了 px、rpx、百分比优先 px，需要等比缩放时用 rpx
vh / vw谨慎使用官方长度单位文档未列出，各端行为可能不一致撑满屏用 flex: 1，比例用百分比
!
最容易漏掉的一类：

以上大多是"不报错但没效果"。如果你的样式在浏览器正常、真机没反应， 先按这张表核对一遍，再去怀疑别的地方。

A.3

把一个 Web 页面迁移过来的 12 步

动手时对照打勾

拿到一个写好的 Web 页面（或自己的课程作业），按这个顺序改造，能避免反复返工。点一下即可打勾，进度会保存在浏览器本地。

✅ 迁移自查 0 / 12 已完成

把 HTML 拆成 .uvue 文件，并在 pages.json 注册页面路径
路径不带后缀，第一项是启动页
把 div/span/p 全部换成 view 与 text（文字一律进 text）
文字留在 view 里会导致样式不可控
把全局 CSS 移到 App.uvue 的 <style>，页面样式留在页面里
顺手删掉 scoped 属性
删除 float / gap / grid / 伪元素写法，改用 flex + margin
用 A.2 的清单逐条核对
把标签选择器、id 选择器、属性选择器全部改成 class 选择器
顺手检查 class 名里没有特殊符号（只允许字母数字下划线短横线）
把所有文字相关样式（颜色、字号、粗细、行高）搬到 text 的 class 上
父级 view 上的文字样式不会生效
把 querySelector + 直接改 DOM 的代码，全部改成"改响应式变量 + {{ }}"
这是迁移中最需要思维转换的一步
把 onclick / addEventListener 改成 @click，表单改成 v-model
事件里写函数名，不加括号（除非要传参）
替换浏览器 API：localStorage→uni.setStorageSync，fetch→uni.request，alert→uni.showModal，location→uni.navigateTo
对照 A.1 的"存储与网络""路由与页面"两栏
把图片等静态资源移入 static/，并用 image 组件替换 img
放错目录会导致真机上图片不显示
给列表补上 v-for 与唯一 :key，长列表考虑交给 scroll-view
避免"能用但一滚动就卡"
在浏览器与 Android 真机各跑一遍，逐项对比界面差异并记录原因
差异清单就是你自己的排错手册（对应附录 B）
✓
迁移心法一句话：

Web 是"用 JS 指挥 DOM 去做事"，uni-app x 是"用数据描述界面应该长什么样"。 凡是需要"找到元素再操作"的代码，迁移时都要先问一句：这个状态能不能用变量表示？
