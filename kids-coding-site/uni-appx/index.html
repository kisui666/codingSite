先修 & 定位

你会的 Web 知识，在这门课里值多少钱？

本课程默认你已掌握：HTML5 语义标签与表单、CSS3 盒模型 / Flex / 定位与动画、JavaScript 变量与函数 / 数组与对象 / 事件与 DOM 操作 / 基础 ES6（箭头函数、解构、模块）。以上内容不会重复讲授，只会被"翻译"成 uni-app x 的写法。

你已有的 Web 技能在 uni-app x 里的对应物迁移难度最容易踩的坑
HTML 标签（div / span / img） 内置组件 view / text / image，书写在 .uvue 文件的 <template> 中 低 App 端没有"标签",只有组件；文字必须放在 text 里，样式还不继承
CSS3 选择器、继承、伪类、浮动 ucss 子集：只用 class 选择器 + flex 布局（默认竖向） 中 标签选择器 / #id / 伪元素 / float 在 App 端不支持
DOM 操作：document.querySelector、onclick 声明式数据绑定：{{ }} + @click，改数据即改界面 中 没有 window / document，靠改响应式变量驱动 UI
JavaScript / ES6 蒸汽模式直接用 TS/JS；VDOM 模式用 UTS（TS 的超集） 低 写上类型更省心：ref<string>('') 比裸 JS 更早发现错误
npm 包 / 第三方库 uni_modules 插件 + npm（蒸汽模式下纯 JS 库可用） 低 依赖 window、document 的库不能直接用于 App
浏览器 DevTools 调试 HBuilderX 控制台 + 真机运行日志 + uni.showModal 快速验证 低 App 端不能按 F12，调试思路要提前建立
ⓘ
关于"蒸汽模式"与"UTS/VDOM 模式"：

uni-app x 早期版本用 UTS（强类型语言，可编译为 Kotlin / Swift / ArkTS / JS）开发，称为 VDOM 模式； 2026 年推出的蒸汽模式改用标准的 Vue + TS/JS + CSS 子集，渲染性能更高、生态与 AI 工具支持更好， 官方推荐新项目使用。本课程主线采用蒸汽模式，同时在第 10 章与附录 C 讲清两种模式的选型与老项目兼容， 保证你既写得动新项目，也读得懂企业里在维护的老代码。
