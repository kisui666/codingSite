# 汽水老师 · 编程课堂（kids-coding-site）项目描述与项目业绩

> 文档口径：**本项目成果口径**（项目描述 + 本项目已完成的量化成果）

## 一、项目描述

### 1.1 项目背景与定位

面向 **6–16 岁少儿**与**大学生**两类差异极大的学习者，建设一个"能直接上课、能直接自学、能直接交付部署"的在线编程教学站点。项目解决的现实问题是：

| 现实痛点 | 本项目做法 |
|---|---|
| 少儿学编程门槛高：要装 Scratch 客户端、要装 Python 环境、要配解释器 | 全部教学内容在浏览器内完成：Scratch 积木可视化 + 内置 Python 终端模拟器，打开网页即可操作 |
| 编程课"看懂了但不会做"：内容多为图文罗列，缺少动手反馈 | 每课时固定配置动手环节、可点可交互的演练区、星级作业与挑战任务，形成"讲—练—测—作业"闭环 |
| 教师备课与学生自学内容混在一起，批注、疑问、待办无处沉淀 | 全站内置**批注系统**：选中文字写批注、区块加便签、标待办，可导出 Markdown 带走 |
| 大学生课程与少儿课程混排，难度与节奏互相干扰 | 三条独立课程线，各自有首页入口、目录、导航与配色，互不干扰 |
| 教学站点上线成本高：要服务器、要构建、要运维 | 纯静态、无构建步骤，可放任意静态服务器 / 对象存储 / 本地文件直接打开 |

### 1.2 建设目标

1. **一条完整的学习路径**：从 Scratch 图形化启蒙 → Python 语法与算法 → 大学生移动应用开发（uni-app x），三个学段贯通。
2. **一套可复用的内容引擎**：课程内容数据化（大纲、测验、演练区三份数据驱动渲染），新增课时只需加数据，不改页面逻辑。
3. **一套真正的工程化质量保障**：自带链接、HTML、CSS、批注四项自检工具，改完即可一键校验，不靠肉眼。
4. **一份可直接交付的成果**：不依赖任何第三方 CDN、字体或脚本，随拷随用。

### 1.3 建设内容：三条课程线

#### 课程线一：Scratch（6–12 岁，图形化编程启蒙 → 游戏创作 → 创意大师）

| 层级 | 入口页 | 课时数 | 内容主线 |
|---|---|---|---|
| L1 趣味启蒙 | `lesson.html` | 16 课 | 舞台 / 角色 / 积木、事件与运动、外观与说话、造型切换、循环与判断入门 |
| L1 首课独立页 | `lesson-scratch-l1-01.html` | 1 课 | 第 1 课完整课堂版（含 9 组 SVG 教学插图），可单独作为试听课页面 |
| L2 游戏创作 | `lesson-s2.html` | 24 课 | 变量与计分、克隆、侦测、音效、多角色协作，完成多个完整小游戏 |
| L3 创意大师 | `lesson-s3.html` | 32 课 | 数据结构化思维、复杂逻辑拆分、作品打磨与展示 |

- Scratch 线合计 **72 课时**，内置 **337 组积木指令示例**（按事件/运动/外观/控制/侦测/运算/变量等分类着色呈现）。
- 每课固定结构：`subtitle / unit 单元归属 / duration 课时时长 / goals 学习目标 / steps 教学环节 / summary 小结 / knowledgePoints 知识点 / homework 星级作业`。

#### 课程线二：Python（9–16 岁，基础语法 → 游戏与数据 → 算法与 AI）

| 层级 | 入口页 | 课时数 | 内容主线 |
|---|---|---|---|
| P1 基础语法 | `lesson-p1.html` | 24 课 | print / 变量 / 数据类型 / 输入 / 判断 / 循环 / 嵌套 / 图案输出，配 **244 条终端交互演示** |
| P2 游戏与数据 | `lesson-p2.html` | 32 课 | 列表与字典、函数、随机数与猜数字等小游戏，配 **9 个 Canvas 可视化演示** |
| P3 算法与竞赛 | `lesson-p3.html` | 40 课 | 排序、查找、递归、文件与数据处理，配 **13 个 Canvas 算法可视化演示** |

- Python 线合计 **96 课时**，浏览器内**终端模拟器**支持逐条命令回放、输入交互（`input()` 场景可在网页里真的输入并看到输出）。
- 学生不需要安装 Python 环境，也不需要在课堂上处理"环境装不上"的故障。

#### 课程线三：uni-app x 移动应用开发（大学进阶，已掌握 H5 / CSS3 / JavaScript）

- **4 大模块 · 13 章 · 4 份附录 · 18 个页面**，从工程结构一路做到打包发布。
- 每章足量配置：**随堂测验（7–8 题）+ 星级作业 + 动手演练区 + 任务清单**；项目章额外配 **10 项验收清单与排错记录模板**，可直接当课程设计评分依据。
- 两个结课项目：**校园课程表 App**（第 11 章）、**校园二手交易 App**（第 12 章），第 13 章为打包与多端发布（结课章）。

| 模块 | 章 | 主题 |
|---|---|---|
| 模块一 起步 | 第 1–3 章 | 走进 uni-app x、布局与基础组件、样式进阶（ucss 与主题） |
| 模块二 语法与交互 | 第 4–7 章 | 响应式数据与模板语法、事件与表单、组件化与组件通信、页面路由与生命周期 |
| 模块三 数据与设备 | 第 8–10 章 | 网络请求与数据展示、本地存储与全局状态、设备能力与 UTS 插件入门 |
| 模块四 实战与发布 | 第 11–13 章 | 项目①校园课程表、项目②校园二手交易、打包与多端发布 |
| 附录 | A–D | Web → uni-app x 速查表、编译错误与真机问题排错手册、模式选型指南、课程设计选题库与评分标准 |

### 1.4 技术架构与关键实现

**总体形态**：纯静态站点（HTML + CSS + 原生 JavaScript），**无框架、无构建步骤、无外部依赖**（实测：全站 `<script src>` / `<link href>` 外链数为 **0**，仅有 SVG 命名空间与教学示例中的示例域名）。

```
kids-coding-site/
├─ index.html                 站点首页（三条课程线总入口）
├─ lesson.html                Scratch L1（16 课，hash 路由）
├─ lesson-s2.html             Scratch L2（24 课）
├─ lesson-s3.html             Scratch L3（32 课）
├─ lesson-scratch-l1-01.html  Scratch L1 第 1 课独立课堂页
├─ lesson-p1/p2/p3.html       Python P1/P2/P3（24/32/40 课）
├─ uni-appx/                  大学进阶课程（18 页：首页 + 13 章 + 4 附录）
│  ├─ assets/style.css        设计令牌与组件类（改一处全站生效）
│  └─ assets/lesson.js        代码高亮、演练区、测验、任务清单、目录抽屉
└─ assets/
   ├─ annotate.js             全站批注层脚本（51 KB）
   └─ annotate.css            批注层样式（12 KB，用 var(--x, 兜底值) 适配两套配色）
```

**关键实现要点**：

1. **内容数据化引擎**：课时页采用"外壳 + 脚本渲染"结构，`<body>` 仅保留 `#app`，正文由页面内的三份数据驱动渲染——`window.SITE_OUTLINE`（站点大纲与上下章导航）、`window.QUIZ_DATA`（随堂测验题库与解析）、`window.PG_DEMOS`（演练区示例代码与交互动作）。新增一节内容只需追加数据，不触碰渲染逻辑。
2. **单文件多课时路由**：同一 HTML 文件内用 hash 切换多节课（如 `lesson-p1.html#p1-02`），72 + 96 课时仅用 7 个文件承载，显著降低维护与部署成本。
3. **交互演练区（代码 ↔ 手机联动）**：演练区由 `data-playground` 容器挂载，配合 `data-bind` 动作节点，可同步演示"改代码 → 手机界面变化"，共 **43 处**。
4. **浏览器内终端模拟器**：用 DOM 模拟 Python 提示符与输出（`py-prompt / py-out / py-dim` 多级样式），支持逐条回放与输入交互，**244 步**演示覆盖 P1 全部语法点。
5. **Canvas 算法/数据可视化**：共 **34 个** Canvas 演示，用于循环图案、列表变化、排序查找过程等抽象概念的可视化。
6. **全站批注系统（不侵入课程内容）**：不改动任何课程正文文件，也不依赖本站特有类名，可整体移植到其他教学站点：
   - 三种形态：**高亮**（选中文字 → 黄/绿/粉 + 写批注 + 待办 + 引用）、**便签**（区块右上角「＋ 便签」写整块意见）、**待办**（小节级加入待办清单，跨页汇总可勾完成）；
   - 锚点容错：以"容器元素路径 + 容器内字符偏移 + 文字签名"定位，重新加载时校验签名，不一致则标记"定位失败"，绝不乱贴；
   - 动态作用域：批注按「文件名 + `::` + 当前标题」分桶，并用 MutationObserver 在整块重渲染后自动贴回当前课时的批注，解决单文件多课时互相串批注的问题；
   - 数据与流转：`localStorage` 单键 `uxa_annotations_v1` 存储，支持复制为 Markdown、下载全站/本页 JSON、下载 Markdown 文件，导入为合并模式（同 id 覆盖），跨页定位用 `?uxa=<批注id>`。
7. **适配与可维护性**：批注层与大学课程共用同一份文件，样式用 `var(--x, 兜底值)` 适配两套配色方案；设计令牌集中在 `style.css`，改一处全站生效。

### 1.5 质量保障体系（项目自带 4 个自检工具）

| 工具 | 作用 |
|---|---|
| `check-site-links.js` | 通用链接完整性：页面内引用的文件是否都存在 |

### 2.2 功能与技术成果

1. **建成一套可复用的课程内容引擎**：`SITE_OUTLINE / QUIZ_DATA / PG_DEMOS` 三份数据驱动全部课时页渲染，新增课时只加数据、不改逻辑，课程线可持续扩展。
2. **建成单文件多课时路由**：168 个少儿课时压缩在 7 个入口文件中，通过 hash 切换并自动维护"上一课/下一课"导航与目录，部署与维护成本大幅降低。
3. **建成全站批注系统（51 KB + 12 KB）**：3 种批注形态、3 种导出方式、导入合并、跨页定位、锚点容错与重渲染自动贴回，教师备课与学生笔记共用一套，且**不侵入任何课程内容文件**、可移植到其他站点。
4. **建成零依赖交付形态**：无框架、无构建、无 CDN 外链（实测外链脚本/样式数 = 0），可放静态服务器、对象存储，也可本地双击直接打开使用。
5. **建成四道自动化质量关卡**：链接、HTML、CSS、批注回归，全部可一键运行并已实测通过，避免人工核对造成的内容与链接腐化。
6. **建成配套教学与验收材料**：附录 D《课程设计选题题库与评分标准》、附录 B《编译错误与真机问题排错手册》、项目章 10 项验收清单与排错记录模板，可直接用于课程设计布置与评分。
